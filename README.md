# 🩺 Diabetes Prediction System

A Machine Learning web application that predicts whether a person is Diabetic or Non-Diabetic using the K-Nearest Neighbors (KNN) algorithm.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Gradio

## Project Structure

Diabetes-Prediction-System/
│── diabetes.csv
│── train_model.py
│── app.py
│── diabetes_model.pkl
│── scaler.pkl
│── requirements.txt
│── README.md

## Installation

```bash
pip install -r requirements.txt
```

## Train Model

```bash
python train_model.py
```

## Run Application

```bash
python app.py
```

## Deployment

Upload the project to GitHub and deploy it on Render.
